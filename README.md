# pair-wise-yf-45 影视剧组拍摄通告与资源冲突编排

源提示词摘要：为剧组制片、导演、演员统筹和场记提供通告编排工作台，维护场次、演员档期、场地与器材占用，自动发现资源冲突，支持拖拽排序、状态流转、版本快照、撤销恢复和离线草稿。

## 操作单元式撤销（不再整版恢复）

每次**场次修改、拖动顺序、状态流转、锁定/解锁、冲突豁免**都落为一条带全局编号的**操作单元**（`src/core/server.ts`），记录提交人、时间和本次触及字段的旧值/新值；场次现场完全由未撤销操作回放得到（`src/core/engine.ts` 的 `project`）。

- **字段级撤销**：撤销一个单元只回退它当前仍拥有的字段；之后别人已生效的场地/器材等改动保持现场，冲突按最新现场立即重算。
- **并发控制**：提交携带 `expectedSeq` 乐观基线。两名制片几乎同时撤销同一项时，先到者成功，后到者收到 `stale`，错误体带**最新操作编号**与**最新冲突说明**；对齐编号后可再次提交。
- **越权**：撤销按操作类型与原提交人角色校验（`canUndo`）。演员统筹撤销制片确认过的锁定或豁免按越权拒绝；制片确认的锁定/豁免仅制片可撤销。
- **幂等**：同一 `requestId` 重复提交重放首次结果，不会多出第二条操作记录。撤销请求使用确定性键 `undo-op{编号}-by-{身份}`，失败重试天然幂等。
- **写入失败**：撤销先进入持久化的**待撤销清单**，服务端写入失败不推进编号、不改现场；重试从**原基线**继续，也可选择"按最新编号对齐后重试"或放弃。
- 版本快照保留为只读存档参考；需要回退时到"操作单元"页按单元撤销，避免覆盖他人随后的改动。

模拟服务端用 `localStorage` 持久化并通过 `storage` 事件跨标签页同步，可开两个浏览器标签（分别选择两名制片）复现并发场景；历史页底部"故障演练"可注入一次写入失败。

`npm run verify` 运行 `scripts/verify.ts` 中的 40 项验收断言。
